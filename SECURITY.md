# Security Policy

## Supported versions

Security fixes are applied to the latest version on `main` and, once published, to the latest release.
Version 1 (`jcadf/iCorrVision_2D`) is frozen and receives no fixes.

## Reporting a vulnerability

Please do not open a public issue for a security problem. Write privately to
**jmc.xavier@fct.unl.pt** with:

- a description of the problem and its impact;
- the iCorrVision version or commit, the Python version and the operating system;
- steps or a small example that reproduce it.

You will receive an acknowledgement as soon as possible. We will work with you on a fix and agree on
when to disclose the problem publicly.

## Scope

iCorrVision is a desktop and command-line tool that reads image files and configuration (TOML) files.
Reports about unsafe handling of such input files, or about the build and release process, are welcome.
